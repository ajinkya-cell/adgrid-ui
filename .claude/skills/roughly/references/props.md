Generated by `scripts/sync.mjs` from the component sources. Don't edit by hand.
Use the namespaced components (`Roughly.Circle` …); they accept every prop below.
`<Roughly type="…">` only forwards a subset (and prefixes arrow props with `arrow`).

Deprecated props are listed last per component; don't use them.

- `ArrowPlacement` = `\| "top" \| "top-right" \| "top-left" \| "bottom" \| "bottom-right" \| "bottom-left" \| "left" \| "right"`

| Prop | Type | Description |
|---|---|---|
| `children` | `React.ReactNode` | Target element or text to point to (optional; if omitted, renders standalone) |
| `placement` | `ArrowPlacement` | Direction from which the arrow points toward the target (default: "top-right") |
| `size` | `number` | Overall scale of the arrow: length, arrowhead and target gap grow together (default: 1) |
| `bend` | `number` | Signed arc bend, -1 to 1 (0 = straight). Unset = auto: the sign and depth that land the head on the target for this placement (±0.32 corners, ±0.2 sides). Override only the depth, keep the auto sign (default: auto) |
| `variant` | `ArrowVariant` | Curve shape: 'curved' (single arc) \| 'straight' \| 's-curve' (default: "curved") |
| `arrowhead` | `ArrowheadStyle` | Arrowhead style: 'open' (>) or 'filled' (solid triangle) (default: "open") |
| `color` | `string` | Stroke color (default: "#F59E0B" Cyber Amber) |
| `strokeWidth` | `number` | Stroke thickness in pixels (default: 2) |
| `iterations` | `number` | Number of pen passes (1 = clean single line, 2 = sketchy double line) (default: 1) |
| `roughness` | `number` | How much the pen passes drift from the ideal arc. The arc itself never kinks (default: 1) |
| `seed` | `number` | Seed for the hand-drawn variation, so several arrows on a page differ (default: derived from placement) |
| `label` | `React.ReactNode` | Callout label text placed near the tail of the arrow |

| `labelFontSize` | `number` | Callout label font size in pixels (default: resolved per font family) |

| `labelPlacement` | `ArrowLabelPlacement` | Relative placement of label around arrow tail: 'auto' \| 'top' \| 'bottom' \| 'left' \| 'right' (default: "auto") |
| `labelDistance` | `number` | Gap distance in pixels between arrow tail and callout label (default: 8) |
| `labelRotate` | `number` | Rotation angle in degrees for playful hand-drawn tilt (default: 0) |
| `labelColor` | `string` | Optional custom text color for the callout label (defaults to arrow color) |
| `labelOffsetX` | `number` | Optional custom horizontal offset in pixels for callout label |
| `labelOffsetY` | `number` | Optional custom vertical offset in pixels for callout label |
| `distance` | `number` | Exact distance in pixels between tail and target; overrides `size` for length (default: 65 × size) |
| `offset` | `number` | Exact gap in pixels between tip and target edge; overrides `size` for the gap (default: 8 × size) |
| `animate` | `boolean` | Whether the drawing stroke animates into view (default: true) |

| `className` | `string` | Additional CSS class names for the wrapping container |

| `labelClassName` | `string` | Additional CSS class names for the callout label |

| ~~flipCurve~~ | `boolean` | @deprecated Use a negative `bend`. Inverts the arc direction |
| ~~bowing~~ | `number` | @deprecated No longer used; the arc is always a single smooth curve |
