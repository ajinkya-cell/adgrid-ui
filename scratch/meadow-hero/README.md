# Meadow Hero (parked)

Removed from the library and `/present` for now. To bring it back:

1. Move `MeadowHero.tsx` to `packages/ui/src/animated/` and `assets/` to `apps/docs/public/meadow/`.
2. Follow the component checklist in `apps/docs/AGENTS.md` (export, registry entry with slug `meadow-hero` in the "Pages" group, renderer case, NEW badge, rebuild `public/r/`).

`assets/grass.webp` is the flattened, defringed grass; the word is positioned against its top edge, so keep that version.
